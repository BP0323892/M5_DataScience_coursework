### 🎵 Featured Project: Spotify Popularity Prediction

**Can audio characteristics predict chart success?**

Built predictive models to analyze 1.69M Spotify chart entries across 73 countries, testing whether intrinsic song features (danceability, energy, acousticness, etc.) can forecast popularity.

**Key Achievements:**
- 🔍 Performed cross-country statistical analysis (Kruskal-Wallis tests) proving regional music preferences differ significantly (p < 0.001)
- 📊 Engineered 87 features including one-hot encoded country indicators and temporal features (song age)
- 🤖 Trained and evaluated Linear Regression and Random Forest models on 1.69M training samples
- 📉 Discovered critical finding: Random Forest failed (R² = -0.535) due to temporal distribution shift—revealing that popularity prediction models decay as musical trends evolve
- 🎯 Achieved 25.7% variance explanation with Linear Regression; identified speechiness, song age, and loudness as top predictors

**Impact:** Demonstrated that while audio features provide genuine signal for chart prediction, continuous model retraining is essential in fast-moving cultural domains.

**Tools:** Python | Pandas | NumPy | Scikit-learn | Plotly | Seaborn | Jupyter Notebook

**Techniques:** ETL Pipeline | Feature Engineering | Statistical Hypothesis Testing | Model Evaluation | Temporal Validation | Data Visualization
